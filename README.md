# 📚 BookBeacon

**Status:** Just Started · Actively Working On

**Tech Stack:** Python · Pandas · NumPy · Matplotlib · Jupyter

## Overview
BookBeacon is an early-stage machine learning project exploring individual rating behavior to build more personalized book recommendations.

I'm currently analyzing the **Goodreads poetry subset** to investigate rating patterns, user activity, and data quality.

## Research Question
**Do Goodreads users interpret the 1–5 star rating scale differently, and can accounting for those differences improve book recommendations?**

## Current Progress
- Analyzed **154,555 reviews** across **47,400 users** and **36,412 books**.
- Investigated missing values, duplicate records, and rating distributions.
- Explored individual users' rating averages and habits.
- Identified differences in average ratings across user activity groups.

## Next Steps
1. Finalize data cleaning and expand exploratory analysis
2. Investigate user-specific rating calibration
3. Build and evaluate recommendation models
4. Explore incorporating written reviews into recommendations
5. Develop the BookBeacon application
